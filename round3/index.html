01 · HTTP RESPONSE

302でSafariへ飛べる？

GitHub Pagesは任意の302応答を出せないため、公開HTTPテストサービス httpbingo.org を使います。同じページ内からのタップと、Xの投稿リンクから直接の違いを比較。

H1 · 対照

302 → 通常HTTPS

まず302転送そのものが正常に動くか確認。

通常の302を開く
H2 · 本命

302 → Safariスキーム

Location: x-safari-https://… による転送を試す。

Safari指定302を開く

H3 · Xの投稿リンクから直行

H2と同じ302リンクです。これをXに貼り、リンク先が最初から302を返す経路を試します。

httpbingoへアクセスする操作では同サービスにIPアドレス・User-Agent等が伝わります。ロード時に外部サイトへのアクセスはしません。サービスのエラーとX側のブロックは別々に記録してください。
